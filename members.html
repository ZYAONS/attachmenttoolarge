The register

Member directory

The Society's register is public, but only in the parts that must be: name, number, rank, date of joining. An email address is a private matter — it does not appear here, and it appears in no form whatever in the API response.

Seats

20 founding seats

Numbers 1 to 20 are founding members, with an extra mark on the card. The figure is taken from the red line that drove us to distraction.

Order

Arranged by number

Not by activity, not by volume of contribution, not by who spotted the problem first. First come, first entered — simple, and fair.

Exit

Leave at any time

Resign from the “My card” page by confirming your number; the server deletes the record outright and keeps no copy.

This is real data, not a hard-coded list This page reads the server's account file (server/data/accounts.json) through GET /api/members. Start the backend on another machine and you will see an empty register — which is precisely how you know it is not lying to you.
