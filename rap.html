How this song was made

We had exactly one rule when writing it: every line has to be traceable to a real ticket. So there is no “dreams”, no “faraway” in here — only 550 and 0x80040610.

  • Rhyme: the hook hammers one sound — large, hard, heart — because that is the only rhyme this subject deserves.
  • Structure: Intro 2 lines → Hook 4 → Verse 12 → Hook → Verse 12 → Outro 4. 38 lines in total.
  • Every number is spelled out for the voice (“twenty-four point seven megabytes”), because speech synthesis reading raw digits out loud is a coin flip.
  • In the hook the error code is deliberately spelled out — “five-five-oh, five-point-three-point-four”. Read it once and you own it for life.
Beat

88 BPM · boom-bap

Kick lands on 1, on the back half of 2, and on 3; the snare refuses to leave 2 and 4. The right hand is eighth-note hats with sixteenth-note ghost notes; the bass follows the kick through Am–F–C–G; then one layer of tape hiss over the whole thing. All of it synthesized live with Web Audio. No audio file.

How to feed it the lyrics

Paste the 38 lines above into the model's lyrics field as one block. Two things we learned: strip the line numbers, and label the hook as [chorus] and the verses as [verse] — the model finds the structure much faster.

For a spoken-only version (no beat), use a voice model like ElevenLabs: pick an English male voice, set the style to "conversational", speed it up 10%.
