Toolchain

Four tools, one obsession

All MIT licensed, no runtime dependencies, small enough to read over lunch. They do not replace your mail client. They knock a hole in the wall that says “attachment too large” and leave the rest to you.

Not a concept

There is a working att in this repository

No install, no sign-up, no dependencies — one Node file is the entire implementation. Every command below was run on real files, and the output is pasted verbatim.

Try: att split "Q3-report_v7_final-FINAL.xlsx" --limit 20MB
It does not treat 24.7 MB as 24.7 MB The server measures the encoded message: 33.8 MB. That single step is where most people go wrong. Split at 20 MB and two messages carry it.

Five subcommands, no dependencies limits reads the database · info decides whether it will send · split cuts it · join verifies and rebuilds · ndr translates the bounce. Everything happens on your machine; nothing is uploaded.

Project matrix

Pick one to start with

Star counts refresh weekly. Status labels are voted on in an RFC, so you never have to guess.

splitter v0.1.0 · works today

Splits by a target limit and generates cross-platform rebuild scripts, verifying every shard with SHA-256. In this repository: cli/att.mjs. Interleaved delivery and resumable transfers are still on the roadmap.

Nodezero depssingle fileshipped
ndr-translator stable

Parses a bounce and returns one sentence: who blocked it, how big, what to do next. Covers 60+ templates, including the versions that gateways rewrite into vagueness.

Nodezero depsin repolibrary + CLI
limits.json continuously updated

Attachment and message size limits for the services we can actually test. Every record carries a reproduction method, a direction (inbound/outbound) and a verification date.

JSON + Schemain repoverified 2025-11
link-shim v0.1.0 · works today

For when a link genuinely is the only option: serves one file behind a random token, with an expiry and a download budget, from your own machine — then shuts itself down. Ships as att-share.

Nodezero depssingle file
Four projects, six executables Splitting and rejoining are separate tools, and the limits database ships with its own query and validate commands. Each is a single executable that needs nothing installed on the target machine — no Node, no installer.

data/limits.json

Attachment limits at a glance

A slice of the database. Limits move with product changes, so always confirm against the official documentation; what we record is the value we last measured and the date we measured it.

ServiceLimitNotesVerified
Outlook.com 20 MB Above this it suggests “send a share link instead” — the phrase this site is named after. 2025-11
Exchange Online (default) 35 MB The Microsoft 365 organisation default; admins can change it, and inbound may differ from outbound. 2025-11
On-premises Exchange (factory) 10 MB A default from the mid-2000s still alive on plenty of internal servers, because nobody dares touch it. 2025-10
Outlook desktop client depends on account The client itself sets no limit — what you hit is the server or a gateway. 2025-11
Corporate SMTP gateway 10–35 MB Usually the first wall you hit, and the hardest one to find. 2025-11
Gmail (reference) 25 MB Included for calibration of our own feelings. 2025-11
QQ Mail (reference) 50 MB The generous corner of the Chinese internet, reminding us the world is not uniform. 2025-09
Or read data/limits.json directly — the CLI reads the same file.
