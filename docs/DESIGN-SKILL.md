# 视觉层 skill —— 从 P3 与明日方舟提炼，并针对本项目已犯过的错

这份文档是**动手前必读**。它由两部分组成：从两款游戏提炼出的设计法则，以及本项目
真实踩过的坑（每一条都有对应的自动检查，防止再犯）。

---

## 一、提炼：两套语言，各自负责什么

### Persona 3（P3）—— 负责「版面张力」

| 法则 | 做法 |
|---|---|
| 高对比排版 | 巨大无衬线标题 + 极紧字距 + 斜切（skew），标题就是主视觉 |
| 硬投影贴纸字 | `text-shadow: 3px 3px 0 主色, 7px 7px 0 黑` 双层错位 |
| 半调网点 | `radial-gradient` 点阵，铺在色带上、边缘用 mask 淡出 |
| 速度线 | `repeating-linear-gradient` 斜向细线，透明度 ≤ 0.12 |
| 巨大衬底数字 | 描边空心字压在区块标题后，`-webkit-text-stroke` |
| 暗时母题 | 一个**具体时刻**作为情绪锚点（本项目：19:59） |
| 碎裂边缘 | `clip-path` 折线切口，让区块不落在直线上 |

### 明日方舟 / 罗德岛终端 —— 负责「仪表可信度」

| 法则 | 做法 | 出处 |
|---|---|---|
| 凯尔希主色 | **骨白 + 医疗绿**（`#f4f1e8` / `#b6d94a`） | 皮肤素材表 |
| 两套字体寄存器 | 古典标题用**衬线大写**；仪表标签用**等宽／窄体大写宽字距** | UI/UX 拆解 |
| 双语装饰 | 每个标签配第二语言小字（`主页 HOME`） | UI/UX 拆解 |
| 骨白印张贴在暗场 | 浅色面板 + 2px 黑框 + 45° 切角 | 同上 |
| 网点纸 + 警戒条纹 | 散点点阵；粗斜条纹（绿/黑）做分隔条 | 同上 |
| 暗角 vignette | 页面四周压暗，视线收到中心 | 同上 |
| 局部马赛克化 | 红青双色错位，**只用于强调**，不做底纹 | 同上 |
| 页边装帧 | 套准标记、标尺刻度、直角走线、刻度弧 | 仪表语言通用 |

**分工原则：P3 管"版面有多冲"，方舟管"它看起来是不是一台真仪表"。两者都不许碰正文可读性。**

## 二、本项目已犯过的错（动手前逐条自问）

| # | 犯过的错 | 后果 | 现在的规矩 |
|---|---|---|---|
| 1 | 缓存号加了但**内容变了不升号** | 我报"已上线"，你屏幕上纹丝不动 | 每次改 CSS／图片，**必须同时升 `?v=`**，并核对线上内容 |
| 2 | 覆盖站内 `color: transparent` 却没补填充 | **所有页面标题消失** | 关渐变必须同时给显式 `color` + `-webkit-text-fill-color` |
| 3 | 浅色面板上放浅色标题 | **白底白字**（CTA 区） | 浅色面板内**所有**后代文字（含 h1/h2/h3/按钮/链接）强制深色 |
| 4 | 把插画（撕裂文档＋大 X）当正文衬底 | 叉子横穿段落 | **任何装饰不得进入正文栏**；装饰只在页边 |
| 5 | 固定定位元素互相压住 | 播放器胶囊压住作战计时 | 四个角各一个固定元素，**互不重叠**，逐个核对 |
| 6 | 只渲染一张截图就报完成 | 你逐页发现自己发现问题 | **逐页截图 + 自动审计**通过后才报告 |
| 7 | 动效不管用户偏好 | — | 所有动画必须在 `prefers-reduced-motion` 下停止 |

## 三、自动审计（`tools/browser-check.mjs` 的 `审计:` 段落）

产出前必须跑通，任何一条失败都算未完成：

1. **对比度**：遍历可见文字，取计算色与最近的不透明背景色，亮度差不足即失败
   —— 直接拦住"白底白字"这类错误。
2. **正文栏洁净**：把正文容器的包围盒与固定装饰层比对，装饰不得覆盖内容列。
3. **固定元素不重叠**：四个角的固定块两两求交，有交集即失败。
4. **标题可见**：每个 `h1/h2` 的计算填充不得为透明、尺寸不得为 0。
5. **缓存戳一致**：页面里所有 `?v=` 必须等于当前戳。

## 四、产出流程

1. 先跑第 3 节的审计，**带着失败项开工**（先复现问题）
2. 改完再跑审计，全绿
3. 逐页截图，人眼过一遍深浅两种主题
4. 升版本戳
5. 推送后**抓线上**复验审计与截图，最后才报告
